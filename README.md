# 专注时间

给自己用的 Mac 小软件。到了我设的时间，它关掉我列出的网站和软件。我想把规矩加严，随时可以。规矩正在生效的时候，我没法把它放松。

名单和钥匙都留在这台 Mac 上。没有账号，也没有统计。源码公开，是希望你先看懂，再决定要不要用。请只装在你自己的电脑上。

A local Mac commitment app. It closes the sites and apps you listed, and it will not let you loosen those rules while they are on.

**要停掉它**，打开终端，执行：

```bash
sudo "/Library/Application Support/FocusGuard/uninstall.sh"
```

输入这台 Mac 的开机密码，不是 Apple ID。窗口里没有停止按钮，这是故意的。

需要 macOS 13 或更新，以及可用的 Touch ID 和 Secure Enclave。请先在系统设置中录入指纹；只有系统版本符合要求，还不能保证这台 Mac 可以保存设置。当前没有密码保存的替代方式。

## 能做什么

打开「专注时间」，有五页。首次启用指纹保存需要管理员授权；系统保护安装并配对后，保存时使用 Touch ID。大约每 5 秒检查一次。

- **网站**。使用时间内，检测到地址或标题里出现屏蔽词，就立即关掉那个标签；关不了标签时，关掉整个浏览器。按字面包含来比，不区分大小写，不会被当成命令。短于两个字时会先问你。
- **应用**。按程序坞里的名字关掉，也可以从正在打开的程序里点选。访达、程序坞、系统设置、启动台和「专注时间」自己不会关。使用时间一到就关。
- **白名单**。一天只能新加一条。在你填的使用分钟里，同名应用不会被关，地址或标题里含有这个词的网页也不会被关。用完后进入停用分钟，黑名单照旧，然后重复。删掉随时可以，删掉不把今天的名额还回来。日历日按北京时间。
- **时间**。从开始到结束。结束如果更早，就守到第二天，星期按开始那天算。例如只选周一、`22:00`–`07:00`，会从周一晚上守到周二早上，不包含周一凌晨。星期里周一是 1，周日是 7。点「开始」会立刻多守一段，不受今天有没有勾选影响。另一行是「修改」时段，默认全天 `0:00`–`23:59`。
- **关机**。默认关着。打开之后，到点前 30 秒弹出置顶大窗口；只有点击「我马上保存并关机」才能解除提醒，点击后才开始 30 秒关机倒计时。不点击就一直提醒，不会自动关机。确认后，在关机时段内大约每 10 秒重试一次关机。这是关机，电源会断。结束如果更早，就守到第二天。

空名单也可以保存，保存前会再问一次。

## 两道锁

写到磁盘之前，安装程序会再查一遍。只改窗口、绕过界面，也写不进去。

使用时间里，包括「马上开始」还没结束的时候，不能把起止改松，不能去掉已经勾上的星期，不能把这段临时时间缩短。

修改时间以外，不能删网站，不能删软件，不能改关机计划。白名单随时可以删。一天只能新加一条白名单，删掉也不把这一天的名额还回来。修改时间默认全天，所以还没把它收窄并保存之前，使用时间之外仍然可以删黑名单、可以改关机。收窄并保存之后，只有那段里能做这些事。

加网站、加软件，任何时候都可以。更严的方向一直开着。

## 保存之后，电脑上有什么

第一次保存成功，会：

- 把「专注时间」放进「应用程序」，并留一份副本
- 在 `/Library/Application Support/FocusGuard` 写下 `config.conf`、校验文件 `config.mac`、钥匙 `seal.key`，`.backup` 里各有一份
- 钥匙在第一次保存时在本机随机生成，用来做 HMAC-SHA256。配置被改坏或删掉，会用对得上的那份写回去。只换掉一把钥匙，也会被另一份盖回
- 给这些文件加上系统的 `schg` 标记，避免随手删掉
- 注册两个开机就运行的系统服务：一个负责关闭，一个负责把被删掉的文件和窗口拉回来
- 启用 Touch ID 后，注册独立的保存服务。它只接受已配对账户、指定应用和指纹密钥签名批准的配置保存，不提供任意命令执行入口
- 登录后重新打开窗口。点红色关闭按钮或「后台运行」会隐藏界面，后台继续运行；点击程序坞图标重新打开，无需密码

配置本机账户可以读。钥匙只有管理员能读。

Touch ID 使用苹果的 LocalAuthentication 和 Secure Enclave 接口。指纹本身不会交给这个应用；应用也不保存开机密码。安全隔区加密的密钥引用只保存在本机用户目录，不包含可导出的私钥。保存服务会核对一次性请求及本次配置的签名，再执行相同的时间和名单限制。首次安装系统服务仍需管理员审批，macOS 可能要求输入账户密码。指纹验证取消、不可用或失败时不保存，不会自动改用密码保存。更改已录入的指纹后，需要重新配对；重新编译或更新应用后，也可能需要在保存按钮旁的菜单中选择「重新启用指纹保存」。目前没有面部认证功能。

## 安全

它挡的是手滑，和当时想放松的我。

- 关闭窗口和按 Command-Q 都会转入后台运行，不会停止保护。大多数退出信号被忽略。真正的关机、重启、注销会放行
- 使用时间内不能把时间表写松。修改时间外不能删名单、不能改关机
- 配置和钥匙各有两份。对不上校验码，就用备份写回
- 程序或脚本被删掉之后，守护进程大约每 5 秒拷回来，并把窗口重新打开
- 安装暂停标记和关机状态保存在管理员控制的保护目录，拒绝符号链接、管道和所有者不正确的文件，避免普通账户用临时文件暂停保护
- 系统自带的那几个程序不会被关，避免电脑没法操作
- 词按字面比较。配置里写成 `$(...)` 这样的字，也只是一个词，不会拿去执行

下面这些，请在安装前就知道：

- 有开机密码的人，可以运行上面的卸载脚本，也可以同时换掉两份钥匙和配置。请把它当成你留给自己的出口
- 在 macOS 恢复模式里，可以清掉 `schg`
- 很短的词会关掉很多无关网页
- Safari，以及 Chrome、Edge、Brave、Arc 这类浏览器，按标签关。某一个标签关不掉时，关掉整个浏览器。Firefox、LibreWolf、Tor Browser、Orion 只能看窗口标题，对得上就退出整个程序，后台标签可能还在
- 程序坞里的名字对不上，软件就关不掉
- 关机时段会真的关掉电源。不要把不能中断的事放在那段时间里
- 从网页下载的压缩包没有苹果公证。第一次若打不开，在访达里按住 Control，点「专注时间」，选「打开」
- 关标签时，系统可能询问是否允许控制浏览器。需要允许。读窗口标题还需要「辅助功能」里的权限

## 隐私

没有注册，名单也不会上传，不需要联网校时。同一台 Mac 上的其他账户可以读到网站名单，读不到钥匙。

## 安装

### 用打好的包

在仓库的 Releases 里下载 `专注时间.zip`，解压，打开其中的「专注时间」。首次启用按系统提示完成管理员授权和 Touch ID 配对，之后保存配置用指纹确认。首次安装的管理员审批由 macOS 决定，不能用应用内指纹提示代替它。

请下载与处理器架构一致的发布包，arm64 包用于 Apple 芯片的 Mac。Intel 的 Mac 可以按下面的方法编译 x86_64 包，但自行编译不能补足 Touch ID 或 Secure Enclave；必须同时满足上面的硬件与指纹要求。

### 自己编译

安装 Xcode 命令行工具，下载本仓库源码并进入源码目录之后：

```bash
bash FocusGuard/build.sh
open "专注时间.app"
```

`build.sh` 会先做规则、安全、关机提醒和安装自检，再编译窗口和保存服务、做临时签名，并在源码根目录生成 `专注时间.zip`。压缩包里附有使用说明和 `LICENSE`，应用和这台电脑的处理器一致。临时签名包没有经过苹果公证。

改过代码之后可以再跑：

```bash
bash FocusGuard/guard.sh selftest
python3 FocusGuard/account-selftest.py
bash FocusGuard/install.sh selftest
python3 FocusGuard/security-selftest.py
python3 FocusGuard/shutdown-selftest.py
```

GitHub Actions 会在独立的 macOS 运行器上构建和自检，检查压缩包内容及签名完整性，并保留临时签名的构建产物和 SHA-256 校验文件。CI 构建通过不代表已通过 Gatekeeper、公证或 Mac App Store 审核，也不代替真实设备上的 Touch ID 和浏览器权限验证。

## 配置

平时用窗口就好。文件是纯文本，在 `/Library/Application Support/FocusGuard/config.conf`。示例见 `FocusGuard/config.conf`。

| 字段 | 含义 |
| --- | --- |
| `START`, `END` | 使用时间。`22:00` 到 `07:00` 表示跨夜 |
| `DAYS` | 使用时段开始日的星期。周一 `1`，周日 `7`，例如 `12345`；跨夜的凌晨部分归前一天 |
| `QUICK` | 临时守到这个 Unix 时间 |
| `MSTART`, `MEND` | 允许删改的时段 |
| `SLEEP`, `SSTART`, `SEND`, `SDAYS` | 关机开关、时段和星期 |
| `APP` | 要关的软件，一行一个 |
| `WORD` | 要关的词，一行一个 |
| `ALLOW` | 白名单。`名字\|使用分钟\|停用分钟\|开始的 Unix 时间` |
| `ALLOWDAY` | 最近一次新加白名单的北京时间日期，`YYYYMMDD`。删掉白名单也不会清掉 |
| `INTERVAL` | 检查间隔的秒数。窗口固定写 `5`，脚本把它限制在 2 到 60 |
